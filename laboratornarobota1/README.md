# PP-LAB01. Пакет матеріалів

**Тема:** Консольні математичні розрахунки з валідацією  
**Час:** 2 контактні академічні години (90 хв)  
**Передумови:** PP-L02, PP-L03, PP-L04

Працюйте зі стартовим файлом і карткою свого варіанта. PDF-інструкція лежить поруч із цим каталогом у `../PP-LAB01_Лабораторна.pdf`.

Файли:

- `student_starter.py — стартовий файл без розв’язку`
- `student_variants.json — картки без відповідей`
- `input_helper.py — готовий скінченний числовий парсер`
- `README.md — ця коротка інструкція`

Запуск: `python student_starter.py VARIANT_1_30`. Оберіть номер 1–30 і виконайте перевірки з PDF. Здайте свій файл та короткий звіт із вхідними даними, результатом і обробкою помилкових меж.
